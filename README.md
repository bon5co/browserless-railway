# browserless-railway

Thin wrapper over `ghcr.io/browserless/chromium` for the Railway "Browserless Headless Chrome" template.
It bakes the concurrency and safety defaults into the image (`CONCURRENT=3`, `QUEUED=10`, `TIMEOUT=60000`,
`HEALTH=true`, `ALLOW_FILE_PROTOCOL=false`) so the published template has no blank required variables.
The only deployer-facing variable is `TOKEN`, generated by the template. Tag matches the upstream release.
